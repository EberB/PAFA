**Pregunta que responde:** ¿qué datos se exponen y con qué contrato?

Las APIs de datos, dominio por dominio: qué se expone de una cuenta, con qué nombres de campo y qué
respuestas se esperan de cada entidad. Es la capa extensa y la que más depende de qué flujos habilite
el regulador.
